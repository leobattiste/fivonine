# Foundation and assets

fivonine reuses the owner-authorized Pheelm application patterns: Next.js App Router, Supabase SSR clients, accessible icon controls and responsive application structure. Cinema data, TMDB content, Pheelm accounts, credentials and service-worker caches were not copied.

Geist Sans is the active font, self-hosted through the `geist` dependency. Its SIL Open Font License is included at `public/fonts/Geist-OFL.txt`. The unused legacy Inter font retains its license at `public/fonts/Inter-OFL.txt`. Hugeicons free icons remain the active icon set at 20px and retain their package license. Dependencies retain their respective licenses.

The original local SVG illustrations are retained as legacy preview assets; the redesigned interface uses optimized stock photographs. They represent no real campaign, organizer or donation request. Placeholder copy is illustrative and must not be published as a real fundraising appeal.
