# Foundation and assets

fivonine reuses the owner-authorized Pheelm application patterns: Next.js App Router, Supabase SSR clients, accessible icon controls and responsive floating navigation/modal geometry. Cinema data, TMDB content, Pheelm accounts, credentials and service-worker caches were not copied.

Inter font: SIL Open Font License, included at `public/fonts/Inter-OFL.txt`. Hugeicons free icons: provided by the pinned dependency and its license. Dependencies retain their respective licenses.

The local SVG campaign illustrations and CSS homepage artwork were created for the preview. They represent no real campaign, organizer or donation request. Placeholder copy is illustrative and must not be published as a real fundraising appeal.
